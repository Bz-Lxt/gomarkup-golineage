使用Go语言实现一个全栈企业级资产与全路径血缘分析图谱（参考Mini Neo4j / 关系网络画布）

业务背景：用于追踪企业内部复杂的资产关系（如：服务器-数据库-应用-接口），或者金融反欺诈中的人际关系网络，在网页端提供可视化的图谱查询。

前端页面 (Vue 3 + AntV G6 / Cytoscape.js)：可交互关系拓扑图：支持节点的拖拽、放大缩小、点击高亮相邻节点及高亮"最短路径"。动态节点编辑器：在右侧抽屉里动态为某个节点添加属性（如：IP、责任人、风险等级）。

Go 后端核心实现：内存图数据结构/或图数据库适配：手写一个基于邻接表/邻接矩阵的高性能内存图结构，支持 BFS/DFS 和 Dijkstra 最短路径算法。血缘变更溯源：资产关系发生变化时（如 A 应用不再调用 B 数据库），记录完整的变更流水，支持在前端按时间轴回溯历史拓扑。

文件数与代码量：约 25~35 个 Go 文件，代码量 5500 - 8000 行。
